De licença por pessoa para capacidade compartilhada

Hoje

200 licenças Power BI PPU

  • Todos podem criar e publicar, sem controle
  • Cada novo leitor exige uma nova licença paga
  • Só visualização: sem motor de dados nem IA

Proposta

Fabric F64 + Azure Databricks

  • Cerca de 20 desenvolvedores (licença Pro) publicam

[Milan · ~1 min 15 s] Obrigado, Matheus. O maior gargalo de gestão hoje é o licenciamento. A Saúde Prime paga cerca de 200 licenças Premium Per User. O problema é duplo. Primeiro, governança: todo mundo pode publicar, então não existe separação entre quem desenvolve o relatório e quem deveria apenas consumir. Segundo, eficiência: o PPU é só visualização. A empresa paga caro e continua sem estrutura para Medalhão ou IA. Além disso, cada novo leitor exige uma nova licença. A proposta é migrar para a capacidade F64 do Microsoft Fabric com o Databricks no backend. Nesse modelo, só uma equipe de cerca de 20 desenvolvedores tem licença Pro para publicar, e os demais usuários, inclusive novos, consomem os relatórios sem licença individual. Isso muda a lógica: hoje, ampliar o acesso aos dados significa pagar mais; na proposta, ampliar o acesso não aumenta o custo de licenças.
